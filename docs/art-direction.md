# Orangegame 美术规范

用户已将画风调整为参考 Steam 游戏《装机模拟器》的相对写实风格，工坊采用实用工业环境，硬件采用真实比例、结构和材质表现

竖屏、2.5D 等距工坊、机箱特写和轻松硬件幽默采用既有规格 [1]，写实程度以用户本次要求和《装机模拟器》Steam 产品页为方向参考 [2]

用户本次确认沿用原参考图的经营 UI，暖色纸卡、橙色按钮和图标用于经营控件

硬件、装配工作台和等距工坊继续采用已确认的写实工业方向，控件材质以 [素材接入记录](ui-reference-integration.md) 为本版依据

以下数值均为制作假设值，覆盖尺寸、镜头、颜色和动画，经济价格、经营工时、评价权重和供应参数由数值负责人维护

## 1 视觉方向

场景应让玩家相信这里能够真实采购、装配、测试和交付电脑，设备尺寸、操作空间、部件结构和材料表现共同形成可信感

工坊使用钢制台架、耐磨工作台面、防静电垫、工具挂板、货架和纸箱，设备之间保留搬运和操作空间，环境呈现有人工作的轻微使用痕迹

光照以中性室内照明为主，少量日光辅助看清形状，场景保留明暗层次，接口、安装位和线缆经过点保持可读

幽默通过供应商品牌、员工对话、新闻和测试反馈表达，硬件造型遵守结构，人物也采用自然身体比例

## 2 形体规则

工坊保持等距总览，装配工作台保持机箱近景，特写中优先展示安装位和接口，画风变化不自动改变镜头控制方式

工坊镜头候选采用平行投影，水平转角为 45°，俯角为 35.264°，桌子、机箱、纸箱和工具共用同一镜头基准

工作台候选采用侧面装配、背板理线和外观展示视图，侧面视图突出主板与走线空间，外观展示采用四分之三角度

每种机箱和配件先锁定结构尺寸，再绘制各视图，所有零件按同一像素到毫米映射放置，部件图片的可见轮廓与安装位置相符

独立采购视图可以展示显卡风扇，安装后的显卡必须按插槽姿态摆放，常规水平安装时风扇位于卡的下方，侧面主要看到卡身边缘

主板固定在托盘上，扩展卡挡板对齐机箱后部插槽，前风扇平面朝向前面板，散热器与内存保持各自真实方向

艺术图中的接口位置须与选定板型的结构资料核对，图像生成结果中出现的伪接口、错位插槽或漂浮线头要在部件评审时修正

缩小的接口通过高亮、引出标签和放大视图帮助选择，触控区域可以扩大，部件结构保持真实比例

## 3 材质规则

材质区别主要来自表面粗糙度、反射、纹理尺度和边缘形状，金属、塑料、橡胶、玻璃和电路板要形成不同的视觉响应

<div align="center">

表 3.1 材质制作要求

| 材质 | 画面表现 | 检查重点 |
| --- | --- | --- |
| 机箱喷涂钢板 | 克制的宽高光、真实折边、少量细颗粒 | 板件具有厚度，颜色不随意跳变 |
| 散热鳍片 | 紧密平行结构、细高光与稳定间距 | 鳍片清楚但不形成闪烁条纹 |
| 塑料外壳 | 高光宽且柔和，模具边缘清晰 | 避免所有部件都呈镜面金属 |
| 电路板 | 哑光绿色或深色板面，少量金属焊点 | 芯片、插槽与供电区域可辨 |
| 线缆和橡胶垫 | 弱反射、自然弯曲、克制的表面纹理 | 线缆看起来具有厚度，固定件与走向一致 |
| 玻璃或透明面板 | 柔和反射、边缘厚度、适量内部透视 | 反光不遮住安装和理线信息 |
| 台面、货架和纸箱 | 合理纹理尺度、轻微磨损与接触阴影 | 磨损服务使用感，保持工坊整洁可操作 |

</div>

光源和材料共同形成物体轮廓，正式美术取消贯穿所有物体的黑色漫画描边，选择状态由独立界面层显示

## 4 配色规则

大面积使用灰白墙面、石墨机箱、深色防静电垫和中性色台面，金属、纸箱和电路板通过自然材料颜色区分

橙色作为硬件和场景中的少量点缀，下表保留工业配色候选，当前经营控件的实际色值采用 [UI 系统](ui-system.md)

<div align="center">

表 4.1 配色候选

| 用途 | 色值 | 应用 |
| --- | --- | --- |
| 深色面板 | `#232A30` | 工作台与采购详情界面 |
| 机箱石墨灰 | `#454C53` | 哑光机箱和设备外壳 |
| 浅灰环境 | `#D0D3D4` | 墙面与非操作背景 |

文字、选择描边和错误提示采用独立界面色，正式组合需要在实际手机显示尺寸下检查对比度与辨识度

默认部件以黑、灰和原材料颜色为主，灯效采用当前年代与采购包允许的选项，彩色灯效由玩家设计决定

渲染采用中性白平衡和柔和补光，避免全场橙色滤镜、强烈景深和大面积辉光，未选部件也能看清空间关系

## 5 画面实现

相对写实可以通过高质量图片或三维模型表现，工坊的画风与实时渲染技术分别选择，当前实现方式仍属于评审项

首版候选使用内置图片生成工具绘制主素材，工坊设备和工作台部件按固定视图独立生成，在 Cocos Creator 中按深度和遮挡关系组合

固定视图内保持一致镜头、材质和光照，视图切换使用独立完整部件图，简单旋转二维图片无法得到正确的另一面

任意旋转机箱需要完整三维结构和对应材质资源，这个需求影响素材制作、接口显示和遮挡计算，须作为画面实现选择单独确认

图片记录中的毫米表示结构尺寸，工作台安装和线缆碰撞由空间数据检查，物体看起来能够安装只是视觉判断

接触阴影和遮挡层与部件安装位绑定，移动、拆除或更换部件时同步更新，避免保留已拆部件的阴影

线缆由程序根据保存节点绘制带厚度和阴影的路径，插头、线扣和束线件使用独立图片，各视图采用相同的连接记录

## 6 素材制作

下表延续现有画布候选，属于视觉制作尺寸，最终导出依据缩放清晰度、贴图内存和微信显示测试选择

原图、提示词、切图记录和运行素材分别遵守项目保存约定 [3]，主素材由内置图片生成工具绘制，Figma 用于切片和导出

<div align="center">

表 6.1 制作尺寸候选

| 对象 | 逻辑显示基准 | 制作要求 |
| --- | --- | --- |
| 竖屏界面 | 390×844 | 按安全区和屏幕比例重排 |
| 工坊可视区 | 390×540 | 原图候选 1560×2160，基础导出 780×1080 |
| 单台工坊设备 | 按格对齐 | 常用导出 256×256 或 512×512，完整轮廓透明图 |
| 工作台单视图 | 约 340×480 | 1024×1536 对齐基准，部件独立生成 |
| 采购产品图片 | 按卡片内容缩放 | 512×512 起步，文字与品牌单独组合 |
| 界面图标 | 按导航和资源卡缩放 | 本版 Figma 导出为 192×192，切片边距和控件尺寸采用素材接入记录 |

</div>

纹理按手机最终尺寸绘制，缩小后消失的印刷字与微小元件不作为识别信息，关键规格通过清楚的文字层显示

机箱分为底壳、托盘、前面板、侧板、上盖、硬盘架和风扇，风扇叶片、阴影、线缆和遮挡层分别保存

主板、显卡、散热器、电源、内存和储存各自生成完整独立图，透明区域保留真实透明背景，不能从整机成图恢复被遮挡的零件

旋转叶片采用独立层，装配吸附动画候选为 150—220 毫秒，视图切换候选为 180 毫秒，动作稳定且能说明当前状态

背景单独保存，小图集按界面、工坊设备、采购产品和单机箱视图划分，单图集上限候选为 2048×2048

素材命名使用英文小写与下划线，替换既有资产保持原 Cocos `.meta` 文件及其资源引用标识

## 7 品牌展示

采购卡、包装和贴纸使用正式供应商品牌与系列，熟悉绰号进入新闻和对话，生成图片预留标识位置，文字由独立图层或引擎组件显示

显卡的板卡制造商、图形平台、产品系列和物理版本分别显示

绘图阶段使用项目登记名称或空白贴纸区，产品图片不自行引入未登记品牌

玩家公司标识使用机身上的独立铭牌或印刷区，排风口、螺钉、接口和部件型号保持可见，标识使用统一朝向与比例

界面采用规整网格、清楚的中文无衬线文字和小面积强调色，候选正文为 16—18 逻辑像素，标题为 22—28 逻辑像素

新版评审图需要同时表现工业工坊、可信的机箱安装状态和规整的采购卡片，三者共用材料、色彩和光照语言

新版图采用中性室内光、金属台架、石墨机箱和真实材质，已将显卡调整为水平安装姿态

正式部件的尺寸、接口和正交视图仍需逐件核对

原手绘暖色图保留为历史版本，新版图作为当前画风候选，部件通过镜头、接口、透明边缘与安装对齐检查后进入正式显示清单

美术负责人检查镜头、结构方向、接口位置、比例、材质、透明边缘和缩放清晰度，工作台负责人检查安装数据和空间碰撞

安装素材单独记录主体矩形，机箱脚垫、挡板和安装耳等突出部分保留在完整图片中，不计入主体的物理宽高

固定镜头的机箱侧面与背板采用同一结构，横向投影转换一次；开孔、下层隔板和硬盘架分别核对，采购视图通过仅适用于采购展示

需要精确放置的支架等固定结构采用独立原图裁切层，在 Figma 按游戏安装尺寸放置；主图与独立裁切来源分别记录

浏览器、微信开发者工具和真机分别记录验证结果，当前概念图与规范没有提供实际运行性能、图集内存或完整装配成功的证据
