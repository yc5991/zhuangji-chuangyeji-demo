## 2 决策 3 是「锁上了，但钥匙没做」

**数据里已经有锁定**：

    opening.hard.startingRoutes = ["boutique"]

**仿真器也认识它**（`simulate-economy.cjs` 第 133 行）：

    const gatedAtStart = !opening.startingRoutes.includes(routeId);

**但这个值只被用于报告**（第 376 行输出里的 `gatedAtStart` 字段），**没有任何解锁逻辑**

实测搜索结果：

| 探查项 | 结果 |
| --- | --- |
| 解锁阈值常量 | 未找到 |
| 累计交付计数 | 未找到 |
| 已解锁路线集合 | 未找到 |

**后果：困难档玩家永远无法解锁量产与混合。** 锁是锁上了，钥匙不存在

## 3 决策 5+E 是纯机制

见 [机制草案](market-response-spec.md)：两个维度（调整排产、提前采购）都是**玩家操作**，不对应任何数值改动

**所以它也不能由落地脚本完成**
