## 1 新增 `assets/scripts/domain/reliability.ts`

照抄模型的两个公式：

| 函数 | 内容 |
| --- | --- |
| `failureRate(design, report, gradeMultiplier)` | 基础 4%，热不稳定 ×3、供电余量 <0.2 ×1.8、测试不稳 ×2，上限 60% |
| `escapeRate(testStationHours)` | ≥1 小时 → 6%；≥0.5 小时 → 30%；不测 → 100% |
| `reworkCost` / `escapeCost` | 返工耗材与到货缺陷的金额 |

**代码里写明**：模型是 CommonJS、游戏是 TypeScript，两边不能共享代码 ✗ 所以公式手工保持一致，**数字的唯一来源是设计文件** ✓

## 2 散热现在有代价了
