## 一个关键判断：**3 分以下算中性，不是坏记录**

我第一版把 1 分算成 ×0.7 ✗ 结果**开局就在惩罚玩家** ✗ 而你说的是「**初始是一分，因为初始啥都没卖，所以就没有分了**」✓

> **「没有分」不等于「差评」** ✗ 它是**没有记录** ✓ 所以不惩罚 ✓

**改成：**

    分 ≤ 3  →  倍数 1（没有记录，中性）
    分 > 3  →  倍数 1 + (分 − 3) × 0.15   （5 分时 ×1.3）

**这个判断很重要**：改之前量产 **低于** 精品（34066 对 34971）✗ 因为开局那 0.7 的惩罚 ✓ 改之后关系恢复 ✓
