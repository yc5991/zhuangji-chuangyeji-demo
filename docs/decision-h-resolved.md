## 3 这个结果本身就是一条验证

**为什么只有量产受影响**：

| 路线 | 受什么限制 | 口碑放大有用吗 |
| --- | --- | --- |
| 精品 | **老板的设计工时（96 小时）** | **没用**——客人再多也做不完 ✓ |
| **量产** | **客群规模** | **有用** ✓ |
| 混合 | 工时与台位 | 没用 ✓ |

**这正是你第 43 轮说的那句话**：「**量产的收益由客群决定**」✓ 模型在这里独立地重现了它 ✓

## 4 结论：H 不需要改任何东西

**「每年的总出货量」按字面指的是整个市场的年出货量** ✓ 设计里那个数是 **2.60 亿台（2016）** ✓

**一个手工工坊永远碰不到这个上限** ✓ 所以口碑放大**不受限制** ✓ **这正是「客人要变多」** ✓

**两句话因此不矛盾** ✓

| 你的话 | 对应的实现 | 现状 |
| --- | --- | --- |
| 「客人要变多」 | 口碑高于 1 时客群变大 | ✓ **已实现**（模型默认 `all`，游戏本来就是） |

**所以 H 与决定 4 是同一条，且都已落地** ✓
