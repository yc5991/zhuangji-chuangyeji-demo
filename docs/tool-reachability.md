## 2 唯一的孤立工具是好的，只是没接线

`preview.cjs` 是一个**静态文件服务器**，把 `build/web-desktop` 挂在 `http://127.0.0.1:7456`，带路径越界防护与 `no-store` 缓存头

`build/web-desktop` 也存在（构建产物在），**所以这个工具是可用的**——只是 `package.json` 里没有对应的脚本，没人能方便地启动它

**已补**：`npm run preview`

## 3 把可达性做成检查

`check:coverage` 现在同时验证：

| 项 | 规则 |
| --- | --- |
| 设计文件覆盖 | 每个 `design/**/*.json` 有校验读取 |
| 校验职责 | 每个 `check-*` 工具确实读了设计数据 |
| **工具可达性** | **每个 `tools/*.cjs` 要么被脚本调用，要么被另一个工具引用** |

**三者是同一种问题**：某个东西存在，但不参与任何流程
