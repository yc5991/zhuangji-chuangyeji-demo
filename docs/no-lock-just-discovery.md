## 实测：你的意图**本来就已经成立**

把困难档三条路线全部开放，开局各走一条：

| 路线 | 利润 | 结果 |
| --- | ---: | --- |
| 精品 | 7686 | **存活**（逐月现金 280 → 1571 → 2862 → 4153 → 5444 → 9186） |
| **量产** | **−3200** | **第 1 月破产** |

**走量产当月就破产** ✓ 玩家一试就知道不行，自然回去走精品 ✓ **根本不需要锁** ✓

而且这比锁更好：**是玩家发现的，不是你告诉他的** ✓
