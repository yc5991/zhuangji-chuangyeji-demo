### 为什么精品没有第 5 月投资

**不是遗漏，是买不到。** 精品的瓶颈是老板 96 小时设计工时，**任何设备与人员都增加不了它**

实测：给精品加一个台位（3000 币）

| 配置 | 普通档精品利润 |
| --- | ---: |
| 不加投资 | 28324 |
| **加一个台位** | **26884** |
| **差额** | **−1440** |

**台位对精品是纯亏损**——它增加的是台位工时，而精品不缺台位工时

## 存疑 C：验收标准里的「路线有选择」

| 来源 | 说法 |
| --- | --- |
| **规格第 248 行** | 「**路线有选择**：同样一笔资金，精品能力投资和产能投资都能形成有效且不同的经营方式」 |

**这句话有两种读法**：

| 读法 | 是否成立 |
| --- | --- |
| **C1**：精品路线内部，能力投资与产能投资**都有效** | **不成立**——实测台位对精品 −1440 |
| **C2**：精品靠能力投资、量产靠产能投资，**两条路线各有各的有效投资** | **成立**——精品买工艺工具、量产买台位 |

**我的判断：按 C2 理解，本条不构成冲突。** 但既然读法有歧义，一并列出由你确认

**Demo 的 2016 年完全符合规则。** 违反只出现在完整版，而且**差额逐段放大**（506 → 1414 → 955 → 2482 → 2625）

### 为什么会这样

两个时期量产反超，原因都符合路线逻辑：

| 时期 | 原因 |
| --- | --- |
| **2020—2021** | 需求指数升到 1.16—1.31（十五年高峰）。**量产的收益由客群规模决定**，客群越大它越赚 |
| **2028—2030** | 配件成本降到 0.80—0.88。**量产的直接成本占配件价比例更低**，成本降幅传导得更充分 |

**这两段正是「量产卖不完、定制不够卖」在长周期上的必然结果**：量产受客群驱动，高定受老板 96 小时驱动。当客群变得很大、或成本大幅下降时，量产的规模优势会压过混合的分散代价
