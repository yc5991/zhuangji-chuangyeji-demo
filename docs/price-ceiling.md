# 价格天花板是硬墙，以及一次被推翻的猜测

第 82 轮想验证第 80—81 轮遗留的问题：事件文本承诺的四种应对手段，仿真器支持几种。查的过程中碰到两件事

## 1 事件承诺四种应对，模型支持一种

`market-events.json` 的 `rules.playerCanReactDuringOmen`：

> Stock up on memory and storage, **switch to a cheaper capacity tier**, **reprice the affected model**, or **accept the risk**

| 承诺的应对 | 仿真器是否支持 |
| --- | --- |
| 提前备货 | **否**（第 80—81 轮已证） |
| 换更便宜的容量档 | **否**——配方固定，月内不能改配置 |
| 给受影响样机调价 | **否**——售价固定，月内不能改价 |
| 接受风险 | **是**（默认行为） |

**四种应对里三种是主动的，而模型一种都不支持。** 这不是四件独立的事，是同一件事的四种说法：**玩家可以按月对市场做出反应**

**所以决策 E（提前备货）与决策 5（调整排产）应该看作同一项机制的三个部分**：

| 部分 | 内容 |
| --- | --- |
| 调整产量 | 决策 5 |
| 提前采购 | 决策 E |
| 调整售价 / 配置 | **本轮新增**，机制相同 |

## 2 价格上限是**硬墙**，不是斜坡

拉高静音办公高定的价格，观察接受度：

| 价格 | 接受度 |
| ---: | ---: |
| 5100 | 1.0000 |
| 5400 | 0.8235 |
| 5600 | 0.7059 |
| **5700** | **0.6471** |
| **5701** | **0.0000** |
| 5800 | 0.0000 |

**5,700 到 5,701 之间接受度从 0.647 掉到 0。**

原因在 `customer-model.json` 的 `quiet_pro` 预算上限 `[4500, 5700]`：超过客群预算上限的价格**永远卖不掉**，与接受度公式无关。这是**已记录的设计**，不是缺陷

### 四个产品的最优价都贴着天花板

各自在会用它的路线上实测（普通档）：

| 产品 | 路线 | 现价 | 天花板 | 实测最优价 | 最优价距天花板 |
| --- | --- | ---: | ---: | ---: | ---: |
| 预算办公 | 量产 | 2115 | 2350 | 2150 | 200 |
| 主流游戏 | 量产 | 4566 | 5200 | 4778 | 422 |
| **静音办公高定** | 精品 | 5100 | 5700 | **5687** | **13** |
| **静音创作高定** | 精品 | 11050 | 12400 | **12363** | **37** |

**两个高定的利润最优价分别只比硬天花板低 13 币与 37 币。**

**含义：最优策略就是「把价格定在客户刚好能承受的上限」**，这不是一个权衡取舍，而是一个「找到墙在哪」的问题

**决策 2 用「最优价的一半」正是对的做法**——它主动留出安全边际，而不是贴着墙定价

## 3 我猜决策 2 的办公价定高了，**测下来是错的**

### 我的猜测

实测最优价 2,150，而决策 2 用的是 **2,202**（高出 52 币，2.5% 的利润差）

**所以我推测把办公价改成 2,150 会更好。**

### 实测结果

| 组合 | 2,202（方案） | 2,150（我猜的最优） | 差额 |
| --- | ---: | ---: | ---: |
| 简单 · 量产 | 46069 | **47301** | +1232 |
| 普通 · 量产 | 37174 | **38028** | +854 |
| 简单 · 混合 | **66694** | 63997 | **−2697** |
| 普通 · 混合 | **56983** | 54286 | **−2697** |

**混合路线变差了 2,697，而它是三条路线里最赚的。**

原因：**混合路线也生产办公机型**（每月 5—13 台），降价对它的伤害大于对量产的帮助

**所以决策 2 的 2,202 是更好的选择。我的猜测错了。**

### 为什么错

我在**量产路线**上单独优化办公价，但那个价格同时影响**混合路线**。**单产品、单路线的最优，不等于整个决策集的最优**

路线规则在两种价格下都成立（精品 < 量产 < 混合），所以这个差异不影响三难，只影响收益水平——**而 2,202 的水平更高**

## 4 本轮结论

| 项 | 结论 |
| --- | --- |
| 事件的四种应对 | **三种是主动的，模型一种都不支持**；与决策 5、E 是同一项机制 |
| 价格上限 | **硬墙**（客群预算上限），不是斜坡 |
| 两个高定的最优价 | 距硬墙只有 13 / 37 币 |
| 决策 2 的「最优价一半」 | **正确**——主动留出安全边际 |
| 我的办公价猜测 | **错误**——2,202 优于 2,150，因为混合路线也用它 |
