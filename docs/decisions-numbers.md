## 决定 6：第 5 月投资给谁

**精品买台位的账**：

| 项 | 数字 |
| --- | ---: |
| 不加台位 | 28324 |
| 加一个台位（花 3000） | 26884 |
| **差额** | **−1440** |

**所以精品买台位是亏的**——它缺的是老板的时间，不是台位。

| 路线 | 第 5 月能买什么 |
| --- | --- |
| 量产 | 半自动设备（有效） |
| 混合 | 台位（有效，因为它也做标准机） |
| **精品** | **没有有效的东西可买** |

**建议**：承诺改成「量产与混合」，精品那一格改成「要不要招人」（困难档晚招一人 +2763）。
