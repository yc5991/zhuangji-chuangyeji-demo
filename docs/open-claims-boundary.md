## 2 新覆盖的那一项，以及为什么它没有机械判据

`openGaps[0]`：**「精品与混合路线在第 5—6 月没有投资机会」**

**最直接的判据**：两条路线是否都拿到了第 5—6 月的投资？

实测（决策落地后）：

| 路线 | 第 5—6 月投资 |
| --- | --- |
| 混合 | **有**（决策 1 加第 5 月台位） |
| **精品** | **永远不会有** |

**精品不会有，是因为它买不到有效设备**（台位 −1440 币）✓ 而**决策 6 的解法不是给它加投资，而是把规格的承诺收窄** ✓

**所以这一项的解决方式是改承诺，不是改数据** ✗ **没有任何机械判据能看出来** ✓

### 已如实注明

检查里写明：

> 它无法由数据解决：决策 6 的解法是把承诺收窄到量产与混合，因为精品没有可买的设备。唯一能机械检测的是「两条路线都拿到了第 5—6 月投资」，而那会让缺口的措辞以另一种方式出错。

**并且实测确认**：即使应用全部决策，这一项仍被正确判为「未解决」✓ ——因为它确实没解决（承诺还没改）✓

## 3 这条扩展的价值与边界

| 价值 | 说明 |
| --- | --- |
| 覆盖多了一处 | `openGaps` 现在进入检查视野 |
| **边界被说清** | 有些待办的解法是**改文档或改承诺**，不是改数据 ✗ 检查只能标记它们，不能判定它们 |

**这比假装能判定更有用** ✓ 一个会误报的检查会被忽略 ✓ 一个说明「我这里判不了」的检查仍然有价值 ✓
