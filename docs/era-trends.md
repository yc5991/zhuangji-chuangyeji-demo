# 完整版年代节奏

完整版覆盖 2016—2030 年共 15 个经营年份，Demo 只覆盖其中 6 个月，此前 15 年的推进没有任何数值模型。本文记录年代趋势的取值与依据分级

数值保存在 [年代趋势数据](../design/era-trends.json)，`npm run check:era` 校验年份连续性、依据分级与代际节奏

## 1 依据分级

每个年份都带一个依据等级，避免推演被当成已核实资料

| 等级 | 含义 | 本年数 |
| --- | --- | ---: |
| 已核实 | 来自实际打开并记录在 [市场资料](market-reference.md) 的来源 | 1 |
| 线索 | 只在搜索结果标题中出现、原文未能打开，仅用于确认方向 | 1 |
| 设计推演 | 原创游戏设计，为 15 年安排可玩的节奏 | 13 |

**只有 2016 年是已核实的市场锚点**（IDC 全年 2.60 亿台，同比 −5.7%）。2021 年标为线索，其余 13 年全部是设计推演

## 2 需求与成本指数

指数以 2016 年为 1.00。需求指数乘在公司可触达客群上，成本指数乘在配件价格上

| 年份 | 需求 | 成本 | 年代特征 |
| ---: | ---: | ---: | --- |
| 2016 | 1.00 | 1.00 | 14nm 成熟期，Pascal 与 Polaris 同月换代 |
| 2017 | 0.99 | 1.06 | 内存涨价，多核开始普及 |
| 2018 | 0.99 | 1.04 | 光追登场，显卡换代加速 |
| 2019 | 1.00 | 0.96 | 7nm 与 SUPER 混战 |
| 2020 | 1.16 | 0.94 | 疫情拉动需求 |
| 2021 | 1.31 | 1.02 | 缺货与挖矿高峰（线索） |
| 2022 | 1.10 | 0.98 | 需求回落，库存高企 |
| 2023 | 0.93 | 0.92 | 周期低谷 |
| 2024 | 0.94 | 0.90 | 复苏起步 |
| 2025—2030 | 0.98 → 1.18 | 0.88 → 0.80 | 成熟期，成本继续下探 |

设计意图：**需求指数制造经营周期，成本指数制造技术红利**。2020—2021 的高点奖励提前扩产的玩家，2022—2023 的低谷惩罚压库存的玩家，2025 年之后成本下降让早期投资回本

2023 年需求指数 0.93 低于 2016 年，是 15 年里最差的一年；这与 Demo 中量产路线对需求下滑最敏感的特性一致，完整版里量产路线会在这一年最难受

## 3 代际节奏

节奏来自项目自己的目录：`design/catalog-2016-2020/*.json` 在 2016-01 至 2020-12 之间记录 72 个事件，其中 43 个是平台或处理器发布

| 指标 | 实测值 |
| --- | ---: |
| 事件总数 | 72 |
| 平台或处理器发布 | 43 |
| 每年事件数 | 14.4 |
| 每年发布数 | 8.6 |

发布跨 CPU 与 GPU 两条线，密度足以让玩家的定型设计持续面临过时压力。**发布间隔本身没有从目录推出可验证的固定周期，因此不写成具体月数**

2021—2030 沿用同一密度，等第二阶段目录补齐后替换为真实资料

## 4 待核实缺口

本轮所有外部抓取都被网络策略拒绝，无法打开 IDC 或 Gartner 的年度原始数据，因此记录三个缺口

| 缺口 | 缺少的证据 | 游戏内处理 |
| --- | --- | --- |
| 2017—2020 与 2022—2030 的出货量 | 无法打开年度原始数据 | 按设计推演给出指数，逐年标注依据，接入前需要一次可联网的核实 |
| 2021 年出货 3.41 亿台 | 只在搜索结果标题中出现 | 标为线索，仅确认 2021 年是高峰，不作为已核实数值 |
| 2021—2030 的技术代际 | 目录只覆盖到 2020-12 | 沿用 2016—2020 实测密度外推，第二阶段目录补齐后替换 |
