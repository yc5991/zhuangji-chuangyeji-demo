# Orangegame Demo 试玩

当前版本已在浏览器通过普通难度精品、规模、混合三条路线的六个月界面试玩，项目范围沿用确认规格 [1]

本轮逐月账目、完整存档及剩余验收项见 [六个月本地验收](six-month-demo.md)

## 1 开始试玩

先运行 `npm run prepare:demo` 导入最新设计数据，使用 `npm run build:web -- -Release` 构建，再运行 `node tools/preview.cjs`

打开 [本地试玩](http://127.0.0.1:7456)，首页直接显示当前工坊，首次进入采用一般难度

公司页点击回到标题，可以设置名称、难度，建立公司或继续已有进度

数据来源及内容摘要记录在 `design/demo-baseline.json`，程序直接读取数值负责人保存的经济与客群数据，本轮功能测试不承担数值平衡验算

## 2 自主产品

在工坊进入自主产品，新建平价办公方案，检查处理器、主板、内存、储存、电源、散热和机箱

进入装配，点选部件再点击安装位，或者从下方列表拖到安装位，也可使用辅助装配

内存等密集安装位按最近的合法空位吸附，背板视图的拖放会转换回同一份设计坐标

装配页的布局与拆装入口可以卸下选中部件、调整风扇位置和方向，以及处理可拆除的硬盘架

移动风扇后需重新连接该风扇，卸下主板会同步卸下板上部件，配置与库存继续保留

进入背板理线，选择连接项、来源接口和固定点，确认每条路径，也可使用辅助理线

进入测试，先采购缺件，点击推进工作收货，再制作样机并推进至测试完成

检查结果后命名定价，定型为标准产品，销售库存，后续可以复制改型或安排批量生产

外观页提供工艺、面板、侧板、配色和灯效选择，按钮显示已有设计数据中的费用与工时，正式纹理仍以绘画评审结果为准

测试页显示六个评价维度，并保留用途评分、噪声负担、供电及线缆问题的具体提示

## 3 高定委托

进入订单，接受静音客户委托，预付款立即到账，预算、售价和交付月份随订单保存

按客户偏好调整配色，完成配置、装配、理线和打样，查看噪声、用途评分与需求提示

完成当前修订的制作与测试后交付，修改后的设计需要重新制作或返工验证

到货故障先登记成交及成本，再记退款与物流，每台只产生一次评价，故障电脑不计入月报和结局的成功销量

高定成功交付确认预付款及尾款，逾期退还未赚取的预付款只影响现金

已有设计可以在客户卡片中通过从已有机型开始复制，原有机型保持不变，新委托需要单独采购和制作

## 4 经营进度

每次经营操作自动保存，公司页也提供手动保存入口，刷新后恢复当前工坊，结束的经营恢复到总结页

在线加速、推进工作和离线恢复共用任务记录，离线完成既有工作并停在当月，主动月结进入下个月

月结前检查未完成委托、库存和排产，确认后支付固定开支与到期账款，未完成工作和库存保留

采购页的库存与到货入口分别列出配件批次、预留数量、未售成品和在途采购，成本读取当时的实付记录

设计测试页的客群反馈解释预算、内存、储存、显卡、用途与噪声要求，预计销量随定价、配置和口碑变化

三月的市场消息提供报价预兆，四月公布本局结果，结果会保存，重复读取存档保持原结果

受影响的新采购报价持续至事件规定的月份，旧库存和已确认采购继续按原成本记录

公司页可以查看工具、工位和半自动设备的效果与费用，也可以招聘员工，月报保留每月实际结果和库存反馈

六月结算后展示产品销量、代表作品、客户评价、产能与经营方向，可以回看全部月份和已保存设计

## 5 当前边界

采购界面已显示全部 32 项配件图片，共用同一外壳的型号复用图片，具体型号和规格由卡片文字区分 [2]

图片来自 Figma 导出，采购展示评审记录保存在 `art/figma/procurement-review.json`

工作台接入三种机箱的侧面、背板和全部 32 项配件的固定视图图片，共 39 条安装映射；外观展示暂时复用采购机箱图

图片按主体测量边界放入现有安装位，机箱下层隔板单独覆盖在部件前方；安装位置、理线和拖放继续使用同一份设计

固定视图显示检查不表示已完成完整三维机械碰撞验证，风扇动画和可更换外观面板图片仍待补充

工坊首页使用等距工坊图片与动态经营控件，界面皮肤和硬件安装图片分别加载

程序已按三种板型区分安装位置，并按所选显卡、电源和散热器的尺寸显示

测量布局仍须与正式机箱原图共同校准，当前功能检查不表示已经完成真实机械碰撞验证

2026-10-11 的浏览器发布构建已完成普通难度三路线六个月，逐月报表通过原始账目核对，完整设计及历史报表刷新后保持一致 [2]

六个月功能检查证明月份、保存与交付能够衔接，完整 2—3 小时体验目标尚未经过玩家游玩验证

本轮没有实现账号关联或云存档，微信发布构建已经通过，模拟器三路线及手机真机尚未验收

2026-10-09 使用项目测试号在微信开发者工具中完成首月自主产品和高定委托、三视图、主板拖放、重启存档恢复及主动月结检查

该次工具保留在二月工坊，具体步骤、警告和范围见 [微信模拟器检查记录](wechat-simulator-test.md)，手机真机尚未检查

困难难度读取最新数据中的高定起步限制，量产解锁条件待数值负责人确认，程序保留这个待定状态
