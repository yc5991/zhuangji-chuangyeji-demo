## 2 待用户决定（5 项）

| 事项 | 阻塞原因 |
| --- | --- |
| **路线收益规则三选二** | 四条已确认规则无法同时成立：精品的总利润、产能约束、单台利润优势只能取二 |
| 是否把现价抬到最优价 | 四个样机现价均低于最优价 10%—16%，抬价后困难档可承受亏损月数从 1.2 升到 2.4，需连带重标难度 |
| 困难档量产与混合的解锁条件 | 候选为口碑阈值、现金阈值、月份门槛或完成 N 台高定 |
| 口碑高于 1 是否放大客群 | 实测放大后量产在简单档追平混合，混合优势从 5885 缩到 37 |
| 路线是否改为自适应生产策略 | 保留量产卖不完与让产能投资回本不可兼得 |

## 5 为什么还不能标记完成

按目标规则，标记完成需要证据证明整个目标已达成。当前有两类原因阻止标记：

1. **5 项待用户决定**——这些不是难度或不确定性，而是需要拍板的真实设计取舍。尤其路线规则三选二未定之前，路线数值无法最终确定
2. **2 项待外部输入**——完整版 2021—2030 的硬件目录尚未建立，代际内容只能外推

审计脚本会在两类待定都清零时自动报告 `complete`，所以完成与否不由文字判断，而由数据决定
