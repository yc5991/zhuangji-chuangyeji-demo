# 六个月 Demo 本地验收

本报告数值来自 [六个月验收记录](six-month-verification.json)，Demo 是本轮本地试玩版本

普通难度的精品、规模、混合路线均已通过浏览器界面走完 2016 年一月至六月，每月包含实际采购、制作及销售或交付

三个最终存档各保留六份月报，刷新后作品、事务、市场结果及历史报表一致，逐月资金与收入均通过原始账目核对

微信发布包已经构建成功，模拟器三路线尚未验收

本次记录来自 2026-10-11 的本地运行，完整构建摘要、数据来源摘要与逐月证据见 [验收记录](six-month-verification.json)

## 3 账目修复

到货故障现在先登记成交收款及制作成本，再登记销售退款和物流费，电脑与客户保存交付结果，每次交付只产生一次评价

高定交付先收尾款并确认已赚取的预付款，再处理故障退款；故障电脑保留已消耗成本，月报和结局均排除失败交付

销售退款冲减销售收入，逾期退还未赚取的预付款只影响现金，物流单独计入费用

制作成本原先包含返工预留金额，现金却只扣基础耗材；本轮补齐相同金额的现金扣款，经济参数保持原值

存档继续沿用第二版，新增可选交付结果及月报退款字段；旧交付结果按原事务恢复，证据不足的结果保持未知

历史现金、完整设计及旧报表原值保留，旧故障账目缺少成交记录时显示历史统计限制

实现位于 [记账规则](../assets/scripts/domain/accounting.ts)、[经营规则](../assets/scripts/domain/game.ts)、[结局统计](../assets/scripts/domain/summary.ts)

依据 [旧界面故障记录](../.local/playtests/v2/boutique/run.json)，输入框修正前的精品复跑曾自然触发六月故障

故障成交 5,391 后全额退款，另记物流 120，保留制作成本 2,942.80，成功销量为零

该样本保存在 [旧界面故障记录](../.local/playtests/v2/boutique/run.json)，属于修正前构建的独立证据，未并入最终三路线结果

## 5 经营问题

本节结果来自 [三路线运行记录](six-month-verification.json) 及另列的探索存档

精品样本每月只交付一台静音电脑，六个月利润均为负数

固定支出持续高于该样本的单月贡献，需要数值负责人结合更多接单量复盘

规模样本每月销售五至六台办公电脑仍持续亏损，四月涨价进一步压缩利润；设备投资提高效率，也减少了当时可用于备料的现金

依据 [探索存档](../.local/playtests/browser-scale-exploration.json)，另一次规模探索把四月售价调至 2,500，出现五台积压

随后投资使五月资金不足以备齐下一批材料

该探索属于修正前构建的策略样本，保留原归属，最终规模路线采用实际调价及采购操作重新完成

混合样本累计利润为 371，四、五月仍亏损

三条浏览器路线的客户报价与市场抽取不同，结果需要结合完整操作与账目判断

采购数量与批量数量共用界面状态，新局也会保留上次数量；本轮通过界面主动选择数量，后续应评审是否分别保存
