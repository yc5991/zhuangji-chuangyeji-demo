# 游戏界面重做记录 v0.3

当前试玩版 Demo 的界面采用原有示意图中的暖色纸卡、木质栏和橙色按钮，硬件、机箱近景与等距工坊继续采用写实材质

本版页面范围来自 `design/ui-system.json`，运行布局来自 `assets/scripts/Orangegame.ts`，原图、提示词与 Figma 导出均保存在项目内

Figma 是本版使用的素材裁切与导出工具，切片边界用于保持控件形状和透明背景

## 1 页面覆盖

根据 `design/ui-system.json` 中的页面清单，本版覆盖现有的 13 个页面：标题、工坊、产品、工作台、采购、订单、公司、库存、客群反馈、已有机型、月报、经营反馈与结局

工作台覆盖配置、装配、布局、理线、外观与测试，布局仍从装配操作进入，硬件安装位置、拖放判定与连线规则沿用原有逻辑

产品卡显示写实机箱、修订状态、配件参考成本与售价，订单卡显示客户头像、需求、预付款和交付状态

采购卡使用正式供应商品牌与产品系列，供应时间及价格读取当前游戏状态

按 `docs/spec.md` 已确认的采购目录，本期配件仍为 32 款

公司页在月结后绘制实际收入与费用，月报分别展示收入、利润、资金、销量、库存和经营反馈

所有经营数字与文字都由运行中的存档生成，素材只提供无字底板和装饰，静态工坊图内的设备数量由独立资源卡补充说明

公告逐条阅读，月结、建立新公司、批量生产与拆装操作使用相同的纸卡弹窗，主按钮、按下、禁用与选中状态分别使用对应切片

表中尺寸与数量来自原图文件及 `art/figma/full-ui-slice-plan-v03.json`，本版继续使用此前完成的 20 个导航和状态图标

Figma 切片节点为 [39:2](https://www.figma.com/design/1Pd44NBRzvtRWywj1V4bz5?node-id=39-2)，导入文件保留原始位图与可编辑裁切蒙版

Figma 连接工具达到本账户调用额度后，本版通过普通 Figma 编辑器完成导入、检查和导出

实际导出的透明图集保存在 `art/exports/ui/full-v03/full-ui-atlas-v03.png`，导入工具按固定矩形无损拆包，不再次去底或修改颜色

22 个运行切片保存在 `assets/art/workbench/ui/full-v03/`，原图和提示词保存在美术目录，运行素材各自保留相邻的 `.meta` 文件

`.meta` 文件记录 Cocos 资源标识，替换同一路径图片时保留该标识，避免场景或脚本引用失效

九宫格拉伸先保留源图高度，再按控件高度统一缩放，因此小按钮仍能保持圆角、铆钉与缝线的比例

素材对应关系、原图校验值、导出尺寸及拉伸边界记录在 `art/figma/full-ui-slicing-v03.json`，加载清单由该记录生成到 `assets/scripts/ui-art.ts`

## 3 验证依据

界面预览、字体检查和弹窗操作记录保存在 `art/figma/ui-demo-verification-v03.json`，页面截图保存在 `art/preview/ui-v03-*.png`

根据本次测试输出，逻辑测试通过 36 项，设计数据和供应商检查通过，素材检查确认两张原图校验值、22 个导出文件及资源标识完整

网页构建与微信发布构建分别执行，微信包体数字来自构建文件测量，测量记录区分本地文件体积、微信上传体积、模拟器与真机结果

浏览器测试使用临时内存进度覆盖制作、销售、月结和结局页面，测试结束后重新加载原有进度，测试数据不写入玩家存档

本版继续采用 `package.json` 固定的 Cocos Creator 3.8.8 游戏引擎，经营数据、存档格式、采购目录和月结规则均沿用原有范围

旧版素材与工坊生图依据见 [参考界面素材接入记录](ui-reference-integration.md)
