# Orangegame 界面规范 v0.3

当前经营界面沿用用户提供的暖色纸卡、木质导航和橙色按钮，硬件和工坊继续采用写实工业材质

以下尺寸和色值来自 `design/ui-system.json` 及 `assets/scripts/Orangegame.ts`，均为游戏界面的制作值

## 1 页面布局

根据当前页面布局，设计画布为 720 × 1280 像素，顶部状态和行动区采用 198 像素，底部导航采用 92 像素

根据当前控件配置，导航按钮为 128 × 84 像素，图标在独立画布内缩放，选中项使用独立纸卡切片

正文和按钮采用运行时文字组件，长文字缩小或换行，经营数字读取当前存档

工坊首页显示等距场景、资源摘要、排产和月结，产品页显示写实机箱卡、设计列表和修订状态

采购页显示正式供应商品牌、规格、数量和渠道，订单页显示客户目标及委托状态

公司页显示实际月报收支图、经营指标和投资入口，工作台保留配置、装配、布局、理线、外观与测试

## 3 控件行为

主按钮使用 Figma 导出的无字橙色底板，根据当前按钮代码，按下时缩小至 98%，取消或释放后恢复

禁用按钮使用独立底板和弱化文字，触摸不执行动作

纸卡和按钮采用九宫格拉伸，并在小控件中按源图高度统一缩放，以保留边角与装饰比例，背景纸纹按原纹理平铺

导航和资源卡使用透明图标，按钮操作图标由 Cocos Graphics 绘制，Graphics 是引擎中的图形绘制组件

场景图片显示固定设备布局，工位数量和生产状态由独立控件显示

装配区进入设计列表，测试区进入已有设计的测试页

素材加载完毕后只重绘一次，弹窗保持当前状态，遮罩阻止触摸穿透
